# Discord bot

Minimal Discord.js bot base with a `/ping` slash command.

## Setup

1. Create an application and bot in the Discord Developer Portal.
2. Copy `.env.example` to `.env` and fill in the three values.
3. Install dependencies with `npm install`.
4. Register the slash commands with `npm run commands:deploy`.
5. Start the bot with `npm run bot`.

Use `npm run bot:dev` during development to restart the bot when files change.
